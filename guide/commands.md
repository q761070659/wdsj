# 指令与权限

## 指令

| 指令 | 说明 |
|------|------|
| `/customadv grant <玩家> <页面> <成就ID>` | 授予玩家指定成就 |
| `/customadv revoke <玩家> <页面> <成就ID>` | 撤销玩家指定成就 |
| `/customadv reload` | 热重载所有配置 |
| `/customadv list` | 列出所有已加载的成就页面 |
| `/customadv help` | 显示帮助信息 |

## 权限

| 权限节点 | 说明 | 默认 |
|----------|------|------|
| `customadv.admin` | 允许使用所有 `/customadv` 指令 | OP |
